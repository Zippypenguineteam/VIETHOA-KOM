HƯỚNG DẪN CÀI ĐẶT
PC 
1. Tải game trên trang chủ chính thức, chọn phiên bản PC.zip và giải nén
2. Dow thư mục VH tên: archivePC của tôi
3. Vào thư mục game KOM, flow theo đường dẫn này: kingdom-of-marionettes-pc\KingdomOfMarionettes-2.0-pc\game
4. Tại đây bạn sẽ thấy tệp archive.rpa của game
5. Sao chép archive.rpa của tôi, và thay thế tệp archive.rpa của game gốc
6. Khi làm xong quay trở lại game, nhấn mở game và bấm thay đổi ngôn ngữ VN

MAC
1. Tải phiên bản macbook
2. Tải thư mục archiveMAC
3. Cách VH tương tự PC

ANDROID
1. Lên Trang chủ chính thức và Tải phiên bản apk android
2. Tải thư mục VHANDROID.zip
3. giải nén nó bằng Trình quản lý điện thoại có sẵn trong máy, hoặc bạn tải về trên chplay
4. Lên gg tải ứng dụng apk editor => khi cài đặt nhớ nhấn cho phép tải tệp lạ về máy, tắt cái proted ch play đi nhé
5. Sau khi giải nén xong bạn sẽ thấy nhiều tệp, sao chép tất cả và vô ứng dụng apk editor
6. Mở ứng dụng apk editor => bấm chọn một ứng dụng => tìm game KOM => Chỉnh sửa đơn giản
